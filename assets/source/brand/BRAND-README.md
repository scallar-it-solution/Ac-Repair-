# Frostwright brand kit

## Folders
- 01-logo/svg  Master vector files (use these for print, vans, signage, Figma)
- 01-logo/png  High-res PNGs (transparent background unless the name says "on-pine")
- 02-favicon   Copy everything here into your Next.js /public folder, then add head-snippet.html
- 03-social    Ready-to-upload profile pictures, covers, OG image, Instagram template
- 04-brand-sheet  Full overview (PNG, PDF, SVG)
- 05-fonts     Oswald (SIL Open Font License, free for commercial use)

## Which file to use where
- Website header: lockup-horizontal.svg (lockup-horizontal-reversed.svg on dark backgrounds)
- WhatsApp / Instagram / Facebook profile picture: 03-social/profile-avatar-640.png
- Google Business Profile logo: 03-social/google-business-logo-720.png
- Link previews (og:image): 03-social/og-image-1200x630.png
- Invoices, letterheads, signboards: wordmark-pine.svg
- One-colour print, stamps, embroidery: wordmark-black.svg / wordmark-white.svg

## Colours
- Deep pine  #14352C  (primary)
- Ice mint   #BFE8DC  (on dark backgrounds)
- Copper     #C27A4A  (needle tip only, use sparingly)
- White      #FFFFFF

## Rules
- Keep clear space around the logo at least the width of the gauge "O".
- Don't recolour the gauge, stretch the logo or add shadows/gradients.
- Below 48px, use the simplified icon (no snowflake).
